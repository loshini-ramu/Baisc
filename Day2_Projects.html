Academic Projects

1. Phishing URL Detection

Technologies: Python, Flask, HTML, CSS, JavaScript, Machine Learning, Scikit-learn

Description:
Developed a web-based phishing URL detection system that identifies malicious websites using machine learning techniques. The application analyses URL features and predicts whether a website is legitimate or phishing, helping users avoid cyber threats. Designed a responsive user interface and integrated a Flask backend for real-time prediction.

2. Canteen QR Ordering System

Technologies: Python, Flask, HTML, CSS, JavaScript

Description:
Created a QR-based ordering system for the college canteen, allowing students to scan QR codes and place orders directly from their mobile devices. The system includes a user-friendly interface for menu browsing and order management, along with a backend for handling order processing and inventory updates.

3. Quote of the Day App

Technologies: Java, Android Studio, XML, Firebase/API, Material Design

Description:
Developed an Android application that displays a daily motivational quote to users. The app fetches quotes from an external API and presents them in a visually appealing format using Material Design principles. Users can also save their favorite quotes and share them on social media platforms.
